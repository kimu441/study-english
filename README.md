# Eigo Quest（TOEIC Bridge 対策）

TOEIC Bridge 対策専用の英語学習ウェブアプリです。単語と瞬間英作文を Duolingo 風の UI で学べます。
収録範囲は中学〜高校卒業レベルです。
間隔反復システム（SRS）で復習日を自動管理し、学習データはブラウザの LocalStorage に保存します。サーバーは不要です。

## 主な機能

画面下のタブで、次の 5 つの機能を切り替えます。

| タブ | 内容 |
| --- | --- |
| **単語** | 3 つの単語帳から選べます。4 択で、英→日と日→英がランダムに出題されます<br>・**TOEIC Bridge**：頻出単語 500 語（中学 240 語・高校 260 語）<br>・**高校必修800**：高校基礎〜共通テストレベルの重要語 800 語（動詞 300・名詞 300・形容詞・副詞 200）<br>・**マイ単語帳**：自分で登録した単語 |
| **瞬間英作文** | TOEIC Bridge の場面（オフィス・お店・駅・アナウンスなど）の文 131 文（中学 75 文・高校 56 文）。文法項目ごとのステージに分かれています |
| **復習** | 一度でも間違えた問題、「わからない」を押した問題を集めた復習リスト |
| **計画** | 試験日までのカウントダウン、1 日に必要なクエスト数、網羅率、カレンダー |
| **記録** | ストリーク・ヒートマップ・正解率・学習ステータス |

- **レベル切り替え**: TOEIC Bridge の単語と瞬間英作文は、それぞれ「中学レベル」「高校レベル」でマップが分かれています。
- **高校必修800**: このアプリ用に独自に選んだ語です。市販の単語帳（『英単語ターゲット1400』など）の収録語・並び順とは関係ありません。
- **マイ単語帳**: 手持ちの単語帳の単語などを、自分で登録して学習できます。
  - 「1語追加」: 番号・英語・日本語・例文・例文訳を入力（番号・例文は任意。追加後、番号は自動で 1 つ進みます）
  - 「CSV取り込み」: 1 行 1 語で `番号,英語,日本語,例文,例文訳` を貼り付けるか、ファイルを選びます。番号・例文・例文訳は省略でき、表計算ソフトからコピーしたタブ区切りもそのまま使えます。英字を含まない行（見出し行など）は読み飛ばします。
  - 英語が同じ単語は上書きされ、学習記録は引き継がれます。
  - 番号順に 10 語ずつ「No.1〜10」のようなステージになります。
  - 学習計画の範囲にも「マイ単語帳」として選べます。
- **瞬間英作文の解答方法**
  - **口頭で言う**（既定）: 日本語を見て英語を声に出し、「答えを見る」で答えを確認して、「言えた／言えなかった」を自分で選びます。
  - **入力する**: 英文を入力して自動で判定します。別解に対応し、`I'm` と `I am` のような短縮形の違いや、大文字・小文字・句読点の違いは無視します。
- **復習リスト**: 次の場合に、その問題が自動で追加されます。
  - 不正解だった
  - 「わからない」を押した
  - 正解したが自己評価で「もう一度」を選んだ
  - 追加された問題は、**3 回連続で正解**するとリストから外れます（どのタブで正解しても数えます）。手動で外すこともできます。
  - 復習タブで「すべて／単語／瞬間英作文」に絞り込んで復習できます。ミスが多い問題と、最近間違えた問題から優先して最大 10 問出題します。
- **学習計画（計画タブ）**
  - 試験日・網羅したい範囲（単語／英作文 × 中学／高校）・試験直前の総復習期間（なし／3 日／7 日）を設定します。
  - 残りの未学習の問題を、今日から総復習期間の前日までの日数で均等に割り、**1 日の新出数とクエスト数**（1 クエスト = 新出 5 問のレッスン 1 回）を表示します。今日学習した分は今日の目標に含めて計算するので、1 日の途中で目標が変わりません。
  - 今日が復習日の問題数と、復習クエストの回数（1 回 8 問）も表示します。
  - 直近 7 日のペースから、全範囲を学習し終える見込み日を出し、目標に間に合うかを表示します。
  - カレンダーで、日ごとの新出の予定・総復習期間・試験日・学習した日を確認できます。日付をタップすると詳細が出ます。
  - 単語・瞬間英作文タブの上部にも、試験までの日数と今日のノルマを表示します。
  - 単語帳・レベルごとに「今日のゴール」を表示します。その範囲の残りを試験日までの日数で割った 1 日の目標数を、マップのステージに置き換えて「○○（その5）まで進めよう」と示し、マップ上のそのステージに「今日ここまで」の旗を立てます。
- **パス型ステージ選択**: 「未開放」「プレイ可能」「クリア済（★・王冠つき）」が一目でわかるマップ UI
- **今日の復習ウィジェット**: SRS で今日が復習日の問題の数を表示し、ワンタップで復習開始
- **自己評価（SRS 連動）**: 「もう一度／難しい／普通／簡単」を選ぶと、次回復習日を自動計算して保存
- **発音**: 解答後や復習リストで、ブラウザの音声合成で発音を聞けます

## 技術スタック

- React 18 / TypeScript
- Vite 6
- Tailwind CSS 3
- lucide-react（アイコン）
- LocalStorage（データ保存）

## セットアップ

Node.js 18 以上を推奨します。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## 使い方

1. ホーム画面のマップでステージをタップし、「レッスン開始」を押します。
2. 問題に答えて「チェック」を押します。
3. 正誤の表示と解説が出たら、どれくらい覚えていたかを 4 段階から選びます。
4. 選んだ評価をもとに、その問題の次回復習日が更新されます。
5. 「記録」タブで学習の推移を確認できます。

見た目をすぐ確認したいときは、「記録」タブ下部の **「デモデータを入れる」** を押してください。過去 16 週間分の学習履歴と学習状況のサンプルが生成されます。**「データをリセット」** で初期状態に戻せます。

## データモデル

型定義は `src/types.ts` にあります。

- **Card**: 問題文（日本語）、正解（英語）、別解、解説、カテゴリ、ステージ ID、`deck`（`word`／`composition`）、`book`（`toeic`／`core800`／`custom`）、`level`（`junior`／`senior`）に加えて、学習状態を持ちます。
  - SRS: `interval`（復習間隔・日）、`easeFactor`（易しさ係数）、`repetitions`（連続正解回数）、`nextReviewDate`（次回復習日）、`lapses`（忘却回数）、`totalAttempts` / `totalCorrect`
  - 復習リスト: `inReviewList`（リストに入っているか）、`missCount`（ミス回数）、`reviewStreak`（リスト内での連続正解数）、`missedAt`（最後に間違えた日）
- **CustomWord**: マイ単語帳の 1 語（番号・英語・日本語・例文・例文訳）。`AppData.customWords` に保存され、「データをリセット」でも消えません。
- **StudyPlan**: 試験日 `examDate`、範囲 `scope`（`word:junior` など）、総復習期間 `reviewDays`。`AppData.plan` に保存され、「データをリセット」でも消えません。
- **ReviewLog**: 1 回の回答ごとの履歴（日付、評価、正誤、獲得 XP、復習間隔の前後）
- **Stage**: マップに表示されるステージ

## SRS のルール

SM-2 系の簡易版です。実装は `src/lib/srs.ts` の `calcNextReview` にあります。

| 評価 | 連続正解 | 次回までの間隔 | 易しさ係数 |
| --- | --- | --- | --- |
| もう一度 | 0 に戻す | 1 日後 | −0.20（下限 1.3） |
| 難しい | +1 | 約 1.2 倍（最低 +1 日） | −0.15（下限 1.3） |
| 普通 | +1 | 1 日 → 3 日 → 前回間隔 × 易しさ係数 | 変化なし |
| 簡単 | +1 | 3 日 → 7 日 → 前回間隔 × 易しさ係数 × 1.3 | +0.15 |

- 間隔の上限は 365 日です。
- 回答を間違えた場合は、「普通」「簡単」は選べません。
- 「もう一度」を選んだ問題は、同じセッションの最後にもう一度出題されます。
- 間隔が 21 日以上で、連続正解が 3 回以上になった問題を「マスター済」とみなします。

## 弱点自動ピックアップ

実装は `src/lib/session.ts` の `pickSessionCards` にあります。各問題にスコアを付け、上位から選びます。

1. 今日が復習日（期限を過ぎた日数が長いほど優先）
2. 間違い率が高い、または忘却回数が多い
3. 未学習の新出問題（ステージ内のレッスンでは優先度が高く、弱点モードでは若いステージを優先）

単語・瞬間英作文タブの「今日の復習」から始めると、選んでいるレベルの弱点モード（最大 8 問）になります。マップからステージを選ぶと、そのステージの問題を中心に 5 問出題されます。復習タブからは復習リストの問題だけが出題されます。

## XP とレベル

- 正解: 普通・難しいで 10〜12 XP、簡単で 15 XP
- 不正解: 2 XP
- 100 XP ごとにレベルが 1 上がります。

## 問題を追加・編集する

### 単語（`src/data/toeic-bridge-words.csv` / `src/data/core-800-words.csv`）

```csv
level,category,english,japanese,example,example_ja
junior,日常生活,kitchen,台所,My mother is cooking in the kitchen.,母は台所で料理をしています。
```

### 瞬間英作文（`src/data/toeic-bridge-sentences.csv`）

```csv
level,category,japanese,english,alternatives,explanation
junior,過去形,昨日はとても忙しかったです。,I was very busy yesterday.,I was really busy yesterday.,be動詞の過去形 was / were。
```

- `level` は `junior`（中学）か `senior`（高校）です。
- `alternatives`（別解）は `|` で区切って複数書けます。短縮形の違い（`I'm` と `I am` など）や句読点の違いは自動で同じとみなすので、書かなくてかまいません。
- カンマを含む値はダブルクォートで囲みます。`#` で始まる行はコメントです。
- 同じカテゴリの問題は 10 問ごとに 1 ステージになり、11 問目からは「その2」になります。新しい問題はカテゴリの末尾に足すと、既存ステージの中身が変わりません。
- 問題の ID は英語の正解から作られます。正解の英語を変えると別の問題として扱われ、その問題の学習記録は引き継がれません。

## データの保存

学習データは LocalStorage のキー `eigo-quest:v1` に保存されます。

- ブラウザやドメインごとに別のデータになります。
- ブラウザのサイトデータを消すと、学習記録も消えます。
- データ形式を大きく変える場合は、`AppData.version` を上げて移行処理を書いてください。

## トラブルシューティング

**`Failed to resolve import "lucide-react"` と表示される**
依存パッケージが入っていません。`package.json` のある階層で次を実行してください。

```bash
npm install
rm -rf node_modules/.vite
npm run dev
```

**効果音が鳴らない**
ブラウザの仕様で、ページを操作する前は音が出ません。セッション画面右上のスピーカーアイコンがオフになっていないかも確認してください。

**発音ボタンで音声が出ない**
ブラウザの音声合成（Web Speech API）を使っています。非対応の環境や、英語音声が入っていない環境では再生されません。

## バックエンドについて

いまの機能（単語・瞬間英作文・復習リスト・SRS・記録）は、すべてブラウザ内で完結するので、バックエンドは使っていません。
スマホと PC で学習記録を共有したい場合は、ログインと保存用の API が必要になります。そのときは `src/lib/store.ts` の `load` と保存処理を API 呼び出しに置き換えるのが入口です。
